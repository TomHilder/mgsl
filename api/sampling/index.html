    Sampling¶

    mgsl.sample(key, lik, mu, schedule, options, *, calculate_diagnostics=True, batch_size=None, devices=None, vectorize=False, progress=True) ¶

    Draw schedule.n_paths posterior samples with MGSL.

    Chains :func:init (at schedule.tau_start from centre mu), :func:advance (over schedule.taus) and :func:finalize. The samples are approximate: each step replaces the localising distribution by a local Gaussian fit. For a linear model with Gaussian noise and converged solves they are exact.

    The run uses the dtype of mu (float64 needs jax_enable_x64; float32 works, with looser attainable solver tolerances).

    key Array

    Random key (typed or legacy).

    		 required
    lik Likelihood
    		required
    mu pytree

    Centre the paths start from, e.g. mgvi_fit(...).mean. Its structure, shapes and dtypes define the latent.

    		 required

    		required
    options MGVIOptions
    		required
    calculate_diagnostics bool

    Record the local ESS and the CG and Newton statistics. Costs 2 n_samples_mgvi + 1 log-likelihood evaluations per fit. Failure counts are recorded either way.

    		 True
    batch_size int

    Paths per compiled call; batches run one after another and the last one is padded. Default: all paths in one call, kept on the device between steps. Smaller batches bound device memory.

    		 None
    devices sequence of jax devices

    Shard each batch over exactly these devices (batch_size must be a multiple of their number; by default all paths, padded to a multiple). Default: no sharding, whatever devices exist.

    		 None
    vectorize bool

    False (default): within a call, paths run one after another, each with as many solver iterations as it needs. True: paths are batched with jax.vmap, which is faster for cheap models or on accelerators, but every solver loop then runs as long as its slowest path.

    		 False
    progress bool

    Print one line per step to stderr (time, local ESS fraction, failure count). The same lines go to the "mgsl" logger at INFO level.

    		 True

    mgsl.init(key, lik, mu, *, n_paths, tau_start, options, batch_size=None, devices=None, vectorize=False) ¶

    Start n_paths localisation paths at tau_start.

    Each path starts from y = tau_start (mu + delta) + sqrt(tau_start) z, with z standard normal and delta ~ N(0, Lambda^{-1}) a draw from the Gaussian approximation at mu, whose precision metric is Lambda = I + J^T F J at mu (see :func:advance). Each path's first local fit is warm-started at mu. If N(mu, Lambda^{-1}) were the exact posterior, y would follow the exact localisation process at tau_start. Solver failures of these draws are reported by a warning.

    mgsl.advance(lik, state, taus, options, *, calculate_diagnostics=True, batch_size=None, devices=None, vectorize=False, progress=True, _warn=True) ¶

    Advance every path of state along the grid taus.

    At each grid point tau the path's localising distribution is fitted by MGVI, warm-started from the previous centre. The fit is a Gaussian N(xbar, Lambda^{-1}) with precision Lambda = (1 + tau) I + J^T F J at xbar (J the Jacobian of the forward model, F the Fisher metric of the noise model). The observation then moves to the next grid point, dtau later, as if the unknown were a draw from that Gaussian: y += dtau (xbar + delta) + sqrt(dtau) z, with delta ~ N(0, Lambda^{-1}) and z ~ N(0, I) fresh for every step and path.

    Each step is one compiled call (for all paths, or per batch), so the grid's length and values do not cause recompilation.

    mgsl.finalize(lik, state, options, *, calculate_diagnostics=True, batch_size=None, devices=None, vectorize=False, progress=True, _warn=True) ¶

    Draw one sample per path from state.

    Fits each path's localising distribution at state.tau and returns xbar + delta, with xbar the fit's centre and delta ~ N(0, Lambda^{-1}) a draw from it (see :func:advance). The state is not changed, so it can still be advanced further and finalised again. Samples of paths whose fit hit a non-finite log-likelihood are NaN.

    mgsl.mgvi_fit(key, lik, x0, options) ¶

    MGVI fit of the posterior (no localisation), e.g. to find the centre paths start from.

    Runs options.n_iter_mgvi rounds; each draws options.n_samples_mgvi mirrored residuals at the current centre and runs Newton-CG on the sample-averaged negative log posterior. A fit of the full posterior from a cold start usually needs more rounds than the warm-started fits inside a run, e.g. dataclasses.replace(options, n_iter_mgvi=10). Check convergence, e.g. by comparing the centre after more rounds.
